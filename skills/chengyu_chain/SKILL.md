# Chengyu Chain

Use this skill when the user wants 成语接龙.

适用中文场景：
- 成语接龙
- 继续接龙
- 以上一个字接下去

Rules:

1. Treat this as a GM-led抢答 game, not a loose free-for-all.
2. The GM gives a starting idiom or target starting character; the first valid group answer wins the point.
3. Validate that the player's phrase is a real four-character idiom before awarding the point.
4. The accepted idiom must start from the required character for that round.
5. Do not repeat an idiom that already appeared in the visible recent context or the session memory.
6. If the phrase is invalid, repeated, or starts with the wrong character, reject it clearly.
7. Keep the game moving. Do not over-explain unless someone asks for rule clarification.

Behavior:

- This skill does not require a deterministic tool.
- Use normal chat output, but follow the GM rules strictly.
- In game mode, keep the pace fast and avoid long reasoning dumps.
- Do not run web search for normal turns.
